Die App

Ohne Schulmodus läuft die App ohne Konto und ohne Internetverbindung. Alle Daten bleiben verschlüsselt auf dem Gerät.

Im Schulmodus ist die Schule für die Daten verantwortlich. Namen und Fotos der Kinder sowie Klassennamen werden auf dem Tablet verschlüsselt, bevor sie es verlassen; der Server kann sie nicht lesen. Die Übungsdaten (welche Buchstaben wann geübt wurden, die gezeichneten Striche, Erfolg und Übungszeit) kann der Server lesen. Sie werden für die Statistik der Lehrkräfte gebraucht.

Kinder haben keine Konten. Sie öffnen ihr Profil mit einer Folge von drei Bildern. Das erleichtert den Start im Unterricht, ist aber kein Passwortschutz.
