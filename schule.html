Für Schulen

Im Schulmodus arbeiten die Tablets einer Schule mit einem gemeinsamen Schulserver. Lehrkräfte sehen, wie ihre Klassen vorankommen. Namen und Fotos der Kinder kann der Server dabei nicht lesen.

Version 2.0 mit dem Schulmodus wird gerade geprüft und ist noch nicht veröffentlicht.

So funktioniert der Schulmodus

  1. Server wählen

    Die Schule betreibt den Server selbst, über ihren Schulträger oder die kommunale IT – oder sie nutzt den Server von Medien-Sandkasten. Er speichert die Übungen und gibt sie an die berechtigten Geräte weiter.

  2. Tablets koppeln

    Jedes Tablet wird persönlich vor Ort mit dem Server gekoppelt. Das Koppeln ist an eine Anmeldung gebunden und nur kurz gültig.

  3. Kinder und Klassen anlegen

    Namen, Fotos und Klassennamen werden auf dem Tablet verschlüsselt, bevor sie es verlassen.

  4. Üben und begleiten

    Die Kinder üben auf den Tablets. Nach der Synchronisierung sehen die Lehrkräfte die Übungen ihrer Klassen.

Zwei Wege zum Server

Die App funktioniert mit beiden gleich. Die Schule bleibt in beiden Fällen für die Daten verantwortlich.

Selbst betreiben

Die Schule, ihr Schulträger oder die kommunale IT betreibt den Server. Die Daten liegen dann bei der Schule oder ihrem Träger.

Server von Medien-Sandkasten

Medien-Sandkasten betreibt einen Server bei Hetzner, den Schulen nutzen können. Dafür schließt Medien-Sandkasten mit der Schule einen Auftragsverarbeitungsvertrag (AVV). Zu den Bedingungen fragen Sie uns bitte direkt über die Kontaktseite.

Wer sieht was

  • Lehrkräfte sehen nur ihre eigenen Klassen.
  • Die Schuladministration sieht die ganze Schule.
  • Kinder haben kein Konto. Sie öffnen ihr Profil auf dem Tablet mit einer Folge von drei Bildern.
  • Wer den Server betreibt – die Schule selbst oder Medien-Sandkasten –, kann Übungsdaten lesen, aber keine Namen, Fotos oder Klassennamen.

Welche Daten wo lesbar sind

Für Lehrkräfte

  • Fortschritt jedes Kindes und Überblick über die Klasse
  • Heatmaps: wo ein Buchstabe Mühe macht
  • Übungen Strich für Strich noch einmal abspielen
  • Genauigkeit der Erkennung pro Kind einstellen

Leihmodus

Ein Tablet kann einem Kind zum Üben mit nach Hause gegeben werden. Es enthält dann nur die Daten dieses Kindes. Für den Leihmodus braucht es die Einwilligung der Eltern.

Was die Schule braucht

  • Tablets für die Kinder
  • einen Server: selbst betrieben (Schule, Schulträger oder kommunale IT) oder der Server von Medien-Sandkasten mit einem Auftragsverarbeitungsvertrag
  • die Abstimmung mit der oder dem Datenschutzbeauftragten der Schule

Unterlagen zum Datenschutz Entwurf

Für Nordrhein-Westfalen gibt es Entwürfe für Verarbeitungsverzeichnis, Elterninformation, Einwilligung und Löschkonzept. Sie sind noch nicht mit einer oder einem Datenschutzbeauftragten abgestimmt und keine Rechtsberatung. Die Schule bleibt als verantwortliche Stelle selbst zuständig.
