Fragen

Antworten auf das, was Schulleitungen, Lehrkräfte, Datenschutzbeauftragte und Eltern am häufigsten wissen möchten.

Kostet die App etwas?

Nein. Die App ist freie Software. Sie kostet nichts und zeigt keine Werbung. Für den Schulmodus braucht die Schule einen Server. Sie kann ihn selbst betreiben oder den Server von Medien-Sandkasten nutzen; zu dessen Bedingungen fragen Sie uns bitte direkt.

Brauchen wir einen Server?

Für ein einzelnes Tablet nicht: Ohne Schulmodus läuft die App ohne Konto und ohne Internetverbindung.

Für den Schulmodus ja. Dafür gibt es zwei Wege: Die Schule betreibt den Server selbst, über ihren Schulträger oder die kommunale IT. Oder sie nutzt den Server, den Medien-Sandkasten betreibt; dann schließt Medien-Sandkasten mit der Schule einen Auftragsverarbeitungsvertrag (AVV). Mehr zum Schulmodus

Wer kann die Daten sehen?

Lehrkräfte sehen nur ihre eigenen Klassen, die Schuladministration sieht die ganze Schule. Wer den Server betreibt – die Schule selbst oder Medien-Sandkasten –, kann Übungsdaten lesen, aber keine Namen, Fotos oder Klassennamen – diese verschlüsselt das Tablet. Die genaue Aufstellung

Brauchen Kinder ein Konto?

Nein. Kinder öffnen ihr Profil mit einer Folge von drei Bildern. Das ist eine Starthilfe im Unterricht, kein Passwort. Die Bildfolge wird nie an den Server geschickt.

Auf welchen Geräten läuft die App?

Die App ist für Tablets gebaut und hat auch Ansichten für Smartphones. Der Code unterstützt Android, iOS, macOS, Windows und Linux. Für welche Geräte Version 2.0 zuerst erscheint, ist noch nicht entschieden.

Gibt es die App im App Store oder bei Google Play?

Noch nicht. Version 2.0 wird gerade geprüft. Wo und für welche Geräte sie erscheint, ist noch nicht entschieden. Sobald es so weit ist, steht es hier.

Was passiert, wenn ein Tablet verloren geht?

Im Schulmodus kann die Schuladministration das Tablet sperren. Danach bekommt es keine Daten mehr vom Server.

Die Daten auf dem Tablet sind verschlüsselt. Wer ein eingerichtetes Tablet in der Hand hat, kann sie aber grundsätzlich lesen. Die Bildfolge der Kinder schützt nicht davor. Ein Verlust sollte deshalb sofort gemeldet werden.

Was passiert mit den Daten nach Klasse 4?

Das entscheidet die Schule. Sie legt fest, wie lange die Daten aufbewahrt werden, und löscht sie danach in der Verwaltung. Beim Löschen entfernt der Server seine Kopien, und die gekoppelten Tablets löschen ihre ebenfalls.

Daten werden nicht automatisch an eine andere Schule übertragen.

Was ist die Grundschrift?

Die Grundschrift ist eine Schrift für den Anfangsunterricht, entwickelt vom Grundschulverband. Sie geht von Druckbuchstaben aus; Kinder entwickeln daraus nach und nach ihre eigene, flüssige Handschrift.

Mehr dazu unter www.die-grundschrift.de.
